Почему Service не должен знать про req и res?

Потому что service получает уже данные и отвечает за операции над ними и использование функция репозитория. И если мы свяжем сервис с http то будет его трудно тестировать, придется симулировать запросы.

Объясните правило зависимостей: какие слои могут зависеть от каких?

router зависит от -> controller -> service -> repository

Что такое Dependency Injection? Зачем фабрика createTaskService({ taskRepository }) лучше чем import { repo } from './repo.js' внутри Service?

Dependency Injection когда мы подключаем иную БД или сервисы. Фабрика лучше потому что мы можем подменить репозиторий на свой, а если мы их жестко свяжем "import { repo } from './repo.js'" то уже подменить будет сложнее

Зачем нужен .env.example? Почему .env не коммитят в Git?

.env нельзя коммитить потому что там находяться локальные данные разработчика для разработки. По типу api ключей, портов и api бекенда или БД
